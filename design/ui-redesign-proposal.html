UI REDESIGN PROPOSAL

小学数学口算题 · 界面重设计方案

面向家长与小学老师的出题工具。设计目标：让完全不懂技术的用户，30 秒内从「打开页面」走到「打印出一张试卷」。

设计：像素君（UI Designer） · 版本 v1.0 · 2026-09-26 · 仅设计提案，未改动应用代码

1现状诊断

当前首页是一个垂直长表单 + 右侧配置列表。功能完整，但以「程序参数」的视角组织，而不是以「用户任务」的视角组织。以下是四个核心可用性问题：

术语门槛

技术术语直接暴露给用户

「几步运算」「算数项 1 / 算数项 2」「whereIsResult 题型设置」是开发语言。家长的心智模型是「10 以内加法」「两位数减一位数」，而不是「2 步运算 + 算数项范围 1~9」。

缺少引导

首次打开面对空白长表单

没有任何预设或示例，用户必须理解全部参数后才能开始。常见的年级/难度组合（一年级 10 以内、二年级表内乘除……）本可以一键就绪。

流程断裂

「添加口算题」→「生成卷子」两步操作无提示

用户必须先点「添加口算题」把题目组放进 paperList，再点页面最下方的「生成口算题卷子」。这个两段式协议没有任何视觉引导，生成按钮在表单底部、提交前不可点击的原因也不透明。

反馈薄弱

配置结果不可预期

「当前口算题包含的内容」只有几个 Tag，用户无法预览卷子大概长什么样、打印几页、每页几题，直到跳转打印页才能看到结果。

2设计原则

🎯

任务优先

按「选难度 → 调细节 → 生成」的用户任务流组织，而非按参数表组织

🗣️

说用户的语言

界面文案用「几个数相算」「得数范围」，技术术语只留在代码里

⚡

默认即可用

年级预设一键就绪，高级设置渐进展开，不强迫理解全部参数

👁️

所见即所得

右侧实时摘要 + 缩略预览，生成前就知道卷子长什么样

3设计系统（Design Tokens）

暖阳橙 + 知识蓝的暖色教育体系。橙色传递亲和与活力（贴合儿童学习场景），蓝色仅用于信息与选中辅助。全部颜色对白色背景满足 WCAG AA 对比度（正文 ≥ 4.5:1）。

5改进点对照说明

编号改进点现状新设计
1 年级快捷预设 首次打开面对空白表单，需理解全部参数 → 4 张年级卡片，点击即用「默认配置」的同一套数据结构填好参数，用户只需点「生成」。预设数据复用 configStorage 的默认值机制，不引入新存储
2 术语翻译 + 大按钮运算符 「几步运算」radio、「+(加法) -(减法)…」checkbox 密集排列 → 「几个数相算」分段选择器 + 56×56 大号运算符块（满足 44px 触控目标）。底层仍映射到 formData.step / operators，数据结构零改动
3 范围输入滑块化 「算数项 1 最小值/最大值」两组 prepend 输入框，含义需推理 → 「每个数在 __ ~ __ 之间」自然语句 + 双输入框 + 滑块联动。进位/退位/括号/求得数收纳为 chips，点击展开，默认收起减少认知负荷
4 右侧实时摘要 + 缩略预览 只有几个 Tag；生成按钮沉在表单底部，「先添加再生成」两段协议无引导 → sticky 摘要栏实时汇总题型/题数/预计页数，并渲染 4 道样例题的缩略预览。生成主按钮常驻右栏，视觉上始终可达；「添加题组」合并进摘要流程（多题组作为高级模式折叠）
5 配置列表 → 我的方案 右侧独立卡片列，占据 1/3 屏宽，与主表单视觉权重相当 → 收编为右栏下方的轻量列表，「保存当前为方案」入口就地可达，沿用现有 ConfigStorage（上限 10 份、命名规则不变）
⚠️ 边界声明：本方案只涉及首页（/）的表单区重设计。打印页 /print 与 paperLayout.js 排版体系不纳入本次改造——该区域有「一张 .sheet = 一页 A4」的硬约束和实测常量，属高风险区，如需美化应单独立项并配套端到端打印验证。

6分阶段实施路线

Phase 1 · 视觉层

低风险，纯样式
  • 引入设计令牌（CSS 变量），替换 Element Plus 主题色为暖阳橙
  • Header / Footer / 卡片化布局 / 字体阶梯
  • 右栏 sticky 摘要（只读展示现有 formData）

Phase 2 · 交互层

中等风险，改组件不改数据结构
  • 年级预设卡片（映射到现有配置数据结构）
  • 运算符大按钮、分段选择器替换 radio/checkbox
  • 范围滑块（el-slider 双值）与输入框联动
  • 缩略预览（用 psm.js 生成 4 道样例题实时渲染）

Phase 3 · 深化（可选）

需单独评估
  • 多题组流程合并进摘要面板，取消「两段式添加」
  • 移动端适配（当前表单在 xs 下已堆叠，主要优化触控目标）
  • 暗色主题（令牌已预留，工作量小）
✅ 兼容性承诺：Phase 1–2 全程不改 formData 字段、不改 ConfigStorage 存储格式、不改 paperGenerator.js / psm.js 任何生成逻辑——已保存的用户配置无缝兼容，可逐 Phase 上线、逐 Phase 回退。
